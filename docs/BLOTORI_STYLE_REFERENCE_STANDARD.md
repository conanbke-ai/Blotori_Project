# Blotori Style Reference Standard

## 목적

Blotori의 문체 개인화는 모델 재학습이 아니라 생성 요청 단위의 Style Reference로 처리한다.

## 세 가지 모드

1. `preset` — 기존 Blotori 문체 Strategy 사용. 회원가입 불필요.
2. `personal-profile` — 여러 본인 글에서 미리 추출한 추상 Style Profile 사용. V1 타입/생성 계약을 준비하되 프로필 저장 UI는 계정 기능 도입 시 연결한다.
3. `single-post` — 사용자가 직접 제공한 특정 포스팅 본문 1개를 이번 생성에서만 참고. 회원가입 불필요.

## One-shot Reference 규칙

- 참고 글은 사실 근거가 아니다. 건강/전문 정보는 Knowledge Base/RAG가 담당한다.
- 참고 글에서 문장 길이, 문단 호흡, 존댓말/말끝, 소제목 패턴, 질문형 문장 빈도, 전문용어 밀도, 이모지 사용, 도입/마무리 방식 같은 추상적 특징만 참고한다.
- 문장, 제목, 사례, 고유 비유, 고유 표현을 복사하거나 근접 재현하지 않는다.
- 최대 12,000자만 생성 요청에 사용한다.
- 서버 DB/로그에 referencePostText를 저장하지 않는다. observability 로그에도 원문을 기록하지 않는다.
- V1에서는 URL 자동 크롤링보다 사용자가 본인/사용권한이 있는 글 본문을 직접 붙여넣는 방식을 우선한다.

## Personal Style Profile

프로필 예시:

```text
문장 길이: 짧은 편
말투: 친근한 존댓말
문단: 2~3문장
질문형 도입: 자주 사용
전문용어: 중간, 쉬운 해설 병기
이모지: 거의 없음
소제목: 짧은 설명형
마무리: 생활 팁 + 부드러운 CTA
```

프로필은 원문 전체를 저장하는 것보다 추상적 특징을 저장하는 것을 기본 원칙으로 한다.

## 생성 우선순위

사실성/안전/RAG 근거 > 플랫폼 규칙 > Style Reference > 문체 강도/프리셋 세부 표현

참고 포스팅의 내용과 RAG 근거가 충돌하면 참고 포스팅 내용은 무시한다.

## 비용

Style Reference는 기존 글 생성 요청의 instructions에 함께 전달하므로 별도 AI 호출을 추가하지 않는다. `single-post`는 입력 토큰이 늘어나므로 참고 본문은 12,000자로 제한한다.
