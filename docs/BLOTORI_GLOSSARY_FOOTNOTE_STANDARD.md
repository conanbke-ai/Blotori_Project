# BLOTORI GLOSSARY FOOTNOTE STANDARD

## 목적

Blotori의 기본 독자는 일반 블로그 이용자다. 전문성은 유지하되 전문용어를 과시적으로 나열하지 않고, 정확성 또는 이해에 실제로 도움이 되는 경우에만 제한적으로 사용한다.

## 생성 규칙

1. 쉬운 표현만으로 충분하면 전문용어를 쓰지 않는다.
2. 전문용어는 글 1건당 최대 5개를 기본 상한으로 한다.
3. 선택한 용어는 intro / 본문 paragraph / closing 중 최초 등장 1회에만 `*`를 붙인다.
4. 동일 용어에 별표를 반복하지 않는다.
5. 실제 본문에 등장하지 않은 용어는 용어해설에 남기지 않는다.
6. 용어해설은 `* 용어: 쉬운 설명` 형식으로 작성한다.
7. 설명은 일반 독자가 바로 이해할 수 있는 짧은 1문장으로 제한한다.
8. 설명에서 새로운 전문용어를 연쇄적으로 늘리지 않는다.
9. 의료·건강 콘텐츠에서는 특정 자세나 구조 하나를 증상의 확정 원인처럼 단정하지 않는다.
10. 전문용어가 필요하지 않은 콘텐츠에는 용어해설 섹션을 만들지 않는다.

## 처리 흐름

```text
GenerateRequest
  -> 기존 AI 1회 생성
  -> AI가 필요한 전문용어만 본문 최초 1회 * 표시
  -> sections 마지막에 용어해설 후보 생성
  -> normalizeGlossaryFootnotes
       - 용어해설 섹션 탐지
       - 본문 실사용 여부 확인
       - 중복/포함관계 제거
       - 문서 등장 순서 정렬
       - 최대 5개 제한
       - 모든 중복 별표 제거 후 최초 1회만 재부착
       - visualStyle=glossary 승격
  -> Preview / Platform Export
```

추가 AI 호출은 발생하지 않는다.

## 화면 표현

- 일반 본문보다 작은 글씨와 낮은 대비를 사용한다.
- 제목은 `용어해설`로 통일한다.
- 모바일에서는 지나치게 작은 글자를 피하기 위해 본문 최소 12px 수준을 유지한다.
- 본문 흐름을 끊는 팝업이나 툴팁을 기본값으로 사용하지 않는다.

## 플랫폼 내보내기

Rich Clipboard를 지원하는 플랫폼에서는 용어해설을 글 하단의 작은 글씨 영역으로 내보낸다.
Plain Text에서는 closing 뒤에 `용어해설`을 배치한다.

## 예시

본문:

`장시간 같은 자세가 이어지면 전방머리자세*가 나타날 수 있습니다.`

하단:

`용어해설`

`* 전방머리자세: 머리가 몸통보다 앞으로 위치한 자세를 말합니다.`
