# Blotori Writing Style & Intensity Standard

## 목적

Blotori의 문체 선택을 단순한 말투 라벨이 아니라 실제 생성 품질을 제어하는 Strategy로 사용한다.

사용자는 `문체`와 `문체 강도(1~5)`를 독립적으로 선택한다.

- 문체: 어떤 방식으로 설명하고 읽히게 할지 결정
- 문체 강도: 선택한 문체의 고유 특징을 어느 정도까지 드러낼지 결정

강도는 모든 문체를 동일하게 더 가볍거나 더 자극적으로 만드는 값이 아니다. 각 Style Strategy가 자신의 핵심 특성을 기준으로 강도를 해석한다.

## 공통 강도

| 단계 | 라벨 | 의미 |
| --- | --- | --- |
| 1 | 절제됨 | 문체 특징을 최소한으로 적용하고 정보 전달을 우선 |
| 2 | 부드러움 | 문체 특징을 자연스럽게 일부 적용 |
| 3 | 자연스러움 | 문체 개성이 분명하지만 과하지 않은 기본값 |
| 4 | 적극적 | 문체 특유의 장치와 리듬을 적극적으로 사용 |
| 5 | 개성 강함 | 문체 캐릭터를 가장 선명하게 적용하되 정확성·안전·플랫폼 규칙은 유지 |

기본값은 `3`이다.

## 강도 해석 원칙

- 이해하기 쉬운 전문 설명형: 쉬운 재설명, 생활 예시, 비유의 빈도와 설명 친화도를 조절
- 안내·교육형: 단계 안내, 확인 포인트, 행동 기준의 명료도를 조절
- 전문가 칼럼형: 논점, 근거, 조건 구분, 분석 밀도를 조절. 강도가 높아져도 유머·이모지는 늘리지 않음
- 솔직한 후기형: 경험 묘사, 관찰, 장단점의 구체성, 개인 반응의 선명도를 조절
- 편안한 일상형: 생활감, 구어적 연결, 짧은 반응, 개인 관찰의 빈도를 조절
- 감성 에세이형: 장면 묘사, 감정, 여운, 문장 호흡을 조절
- 짧고 담백한 기록형: 압축도, 직접성, 군더더기 제거 수준을 조절. 강도가 높을수록 더 짧고 선명해짐
- 친근한 정보형: 독자 말걸기, 쉬운 풀이, 질문형 소제목, 예시의 빈도를 조절
- 가볍고 유쾌한 문체: 리듬, 자연스러운 위트, 구어적 반응, 비유의 체감도를 조절
- 저장·공유형 정보 콘텐츠: 훅, 짧은 문단, 시각적 강조, 체크리스트, 번호 정리, 요약, 가벼운 CTA의 적극성을 조절

## 저장·공유형 정보 콘텐츠

목표는 `빠르게 읽히지만 중요한 내용은 남는 정보형 콘텐츠`다.

핵심 특징:

1. 독자의 문제·공감 상황을 첫 화면에서 바로 제시
2. 글을 읽고 얻는 이익을 초반에 명확히 안내
3. 핵심 개념은 한 줄 정의로 먼저 제시
4. 짧은 문단, 번호, 체크 포인트, 단계형 구조 적극 활용
5. 중요한 내용은 굵은 강조나 짧은 요약으로 한 번 더 환기
6. 실천법·체크리스트·저장 가치가 있는 내용을 우선
7. 마지막에는 3줄 요약 또는 한눈에 보기 제공
8. 필요할 때만 자연스러운 저장·실천 CTA 사용
9. 클릭베이트, 근거 없는 단정, 과장된 성공 보장 금지
10. 이모지·기호는 내용의 스캔성을 높일 때만 사용하고 남발하지 않음

## 조합 규칙

최종 생성은 다음 우선순위를 따른다.

`사실성·안전 > 사용자 명시 조건 > 문체 Strategy + 강도 > 글 구성 Strategy > 플랫폼 기본 규칙`

단, 플랫폼이 지원하지 않는 표현이나 의료·안전상 부적절한 표현은 문체 강도보다 우선해 제한한다.

`자동 추천`에서도 강도는 유지한다. AI가 주제·플랫폼에 맞는 문체를 선택한 뒤 사용자가 지정한 강도로 그 문체를 적용한다.

`직접 설정`에서는 사용자가 기술한 문체의 특징을 강도 값에 맞춰 절제하거나 강화한다.

## UI

Composer 설정 순서:

`플랫폼 → 카테고리/주제 → 추가 조건 → 글 구성 → 문체 → 문체 강도 → 글 길이/이미지 수`

문체 강도는 1~5 선택형으로 제공하며 기본값은 3이다.

사용자 라벨:

- 1 절제됨
- 2 부드러움
- 3 자연스러움
- 4 적극적
- 5 개성 강함

## 생성 비용 원칙

문체 및 강도는 기존 단일 생성 프롬프트에 함께 주입한다. 문체 검수를 위해 별도 AI 재호출을 추가하지 않는다. 따라서 기본 생성 비용 원칙인 `AI 1회 / 글`을 유지한다.
